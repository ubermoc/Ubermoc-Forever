# Ubermoc Forever

Play World of Warcraft: Forever and Midnight with only a controller. Built around the Steam Deck and Steam Controller, using the game's own art and fonts.

Status: early scaffold (0.0.1). See [CHANGELOG.md](CHANGELOG.md).

## Install
Download the latest zip from Releases and extract `UbermocForever` into the `Interface/AddOns` folder of your `_forever_` or `_retail_` game folder.

## Commands
- `/ubf debug`: toggle debug logging
- `/ubf log`: show recent log lines
- `/ubf pad`, `/ubf padtest`, `/ubf padmap`: controller report, live readout and full button list
- `/ubf layout on|off|status|reset|bind|bar`: action bar layout for the controller
- `/ubf autotest on|off|now`: run the self test by itself on every load and keep the results in the saved variables (for development)
- `/ubf version`: show version and game type
