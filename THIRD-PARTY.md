# Third-party data

## Quest data (Ubermoc-Forever/QuestData.lua)

The quest guide's data is generated by `tools/build_questdata.sh` from [QuestieDB](https://github.com/Questie/QuestieDB)'s Forever data,
with QuestieDB's own corrections folded in (the QuestieDB commit is written at the top of the file). QuestieDB is licensed under the
GNU General Public License version 3, and so is this addon from the version that includes that data on (it was MIT before).
QuestieDB's authors: Logonz (code); Muehe, TheCrux (BreakBB), Drejjmit, Dyaxler, Cheeq, TechnoHunter, Yttrium and everyone else (data).
Nothing of Questie's or QuestieDB's code runs in this addon: only the generated data file is included; the guide's code is our own.

World of Warcraft, its quests and names belong to Blizzard Entertainment.
